Case Studies

Deep dive into the challenges, solutions, and results

Djibouti E-commerce Platform

Overview: Built a full‑featured online marketplace for local artisans and small businesses.

Challenge: No existing platform supported local payment methods and delivery logistics.

Solution: Developed a React frontend with Node.js backend, integrated mobile money APIs.

Technologies: React, Node.js, MongoDB, Stripe/M‑Pesa integration.

Features: Vendor dashboards, order tracking, multilingual support.

Results: Over 50 vendors onboarded in first 3 months, 200+ daily orders.

Base Central CRCS

Overview: Centralised dashboard for the Djibouti Red Crescent Society.

Challenge: Fragmented data across Excel sheets, no real‑time overview.

Solution: ASP.NET Core dashboard with interactive charts and role‑based access.

Technologies: ASP.NET Core, SQL Server, Chart.js, Azure.

Features: Live aid tracking, volunteer scheduling, automated reports.

Results: 70% reduction in reporting time, improved donor transparency.

Iftin Private School of English

Overview: Digital transformation of a growing language school.

Challenge: Manual attendance, no online payment, poor parent communication.

Solution: React + Firebase web app with student portal and online fee collection.

Technologies: React, Firebase, Node.js, Twilio SMS.

Features: Attendance by QR code, grade book, parent notifications.

Results: 100% fee collection on time, 90% parent satisfaction.
